## Research Documents

### Executive Summary

### Competitive Analysis & PRD Research
Comprehensive analysis covering:
- **Part A**: Competitive landscape across 5 categories (screenwriting, storyboarding, production planning, video generation, blocking/shot planning)
- **Part B**: PRD research foundation including target markets, pain points, pricing benchmarks, union compliance requirements
- **Technical Architecture**: Multi-agent framework recommendations, API/model stack, data models
- **MVP vs Full Product**: Phased feature roadmap from MVP through enterprise

## Key Findings

1. **Market**: $1.8B → $14.1B by 2033 (25% CAGR)
2. **Gap**: No platform handles full script-to-production pipeline
3. **Opportunity**: AI blocking automation has zero competition
4. **Tech Stack**: LangGraph + CrewAI hybrid with Claude/GPT-4o for analysis, FLUX/DALL-E for images, Runway for video
